# Step 4 - useState

## 核心知识

1. useState 创建组件状态。
2. setState 更新状态。
3. State 更新会触发组件重新渲染。
4. 不直接修改原始数组或对象。
5. 新状态依赖旧状态时，优先使用函数式更新。

## 实战功能

- 用户列表展示
- 新增用户
- 删除用户
- 用户数量统计
