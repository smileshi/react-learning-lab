### Week 2 调用链

``` text
React Page
    |
    v
React Component
    |
    v
Custom Hook / API Service
    |
    v
Axios / Fetch
    | HTTP Request
    v
Spring Boot Controller
    |
    v
Service
    |
    v
Repository / Database
    | JSON Response
    v
React更新State
    |
    v
页面重新渲染
```

### 最终实战项目：用户管理系统

## 六、每节课的学习与验收规则

  -------------------------------------------------------------------------------------------------
  环节                                      建议时间 要求
